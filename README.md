## ⭐ Featured Project

### UniCEUB Dark Mode Extension
Browser extension officially integrated into the UniCEUB student portal, providing a consistent, maintainable, and performance-aware dark theme to improve accessibility and visual comfort.
- Adopted by a real university platform with active users
- Emphasis on accessibility, UI consistency, and performance-aware styling
- Open-source project maintained as a long-term reference
